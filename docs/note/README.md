## 2. note に貼る手順

1. note で新しい記事を作り、`online-manuscript-paper-pro-note-article.md` の1行目（`# ` を外したもの）をタイトル欄に入れる。
2. 2行目以降を本文欄に貼る。`##` の見出しは note のエディタで見出し（H2）として認識されます。目次は見出しから自動で作られます。
3. **画像は手で入れ替える。** 本文に `![…](images/01-student-home.png)` の形で入っているので、その位置に `images/` の同じファイルをアップロードしてから、Markdown の行を削除します。
4. 画像の直後に置いてある一行を、note の**キャプション欄**に移す。本文に残しても読めますが、キャプション欄のほうが記事が締まります。
5. ハッシュタグ欄に `#GIGAスクール` `#小学校` `#作文` `#国語` `#ICT教育` `#自作アプリ` あたりを入れる。

装飾記号を使っていないので、貼ったあとに崩れるところはありません。

### 画像の大きさについて

撮影は 1280×900 のビューポート、2倍の解像度（2560×1800）で撮っています。ただし**リポジトリに入れる前に、幅 1280〜1600 に縮小して 256色に落としました。** `node scripts/check-project.mjs` の `image-size` が「画像は150KB以内」を見ており、2倍のままだと全点が引っかかるためです。

この検査は、アプリが子どもの端末に送る画像を軽く保つためのものです。記事用の画像を通すために検査を緩めたり `securityExceptions` に `image-size` を足したりはしていません。そこを免除すると、あとでアプリ本体に重いアイコンが入ったときに気づけなくなります。

note の表示幅はいちばん広い場合でも 1280 ほどで、アップロード時に note 側が再エンコードします。縮小によって記事の見え方が落ちることはないと思いますが、原寸で載せたい画像があれば `docs/note/` の外で撮り直してください。29点で合計3.3MBです。

なお `docs/` は GitHub Pages の成果物にも一緒に載ります。アプリの読み込みには使われないので、表示の速さには影響しません。

### 撮れなかったもの

**AI添削の実行結果だけ、画面がありません。** Gemini の APIキーがないと動かない機能で、この作業環境から Google の生成AIのアドレスにも接続できませんでした。鍵を入れる欄そのものは `26-teacher-settings.png` に写っています。記事では「使いたい先生だけが使える」という書き方にとどめ、AIが貼った赤ペンの画面を載せていません。**先生ご自身の鍵で一度動かして、`【AI】` 付きの赤ペンが並んだ画面を1枚追加すると、この節が強くなります。**

## 5. 撮り直すときの手順

この環境ではCDNに出ていけなかったため、**撮影用のコピーを作業ディレクトリの外に作り、そこだけ書きかえて撮りました。リポジトリのファイルは1バイトも変えていません。** `git status` と `git diff` で確認済みです。

普通にCDNへ出られる環境なら、もっと簡単です。

```bash
npm i --no-save playwright peer
node <skill>/scripts/serve.mjs . 4180 /online-manuscript-paper-pro/
node <skill>/scripts/capture.mjs shots.mjs \
  --base http://127.0.0.1:4180/online-manuscript-paper-pro/ --out shots
```

このアプリはビルドが要らないので、`serve.mjs` のルートはリポジトリの直下でよいです。ベースパスの `/online-manuscript-paper-pro/` は省かないでください。`manifest.webmanifest` の `id` と `scope` がこの絶対パスで固定されているため、ルート直下で配ると本番と挙動が変わります。

CDNに出られない環境で撮る場合は、次の3つを撮影用のコピーにだけ施しました。

1. `react` `react-dom` `@babel/standalone` `peerjs` `sweetalert2` `diff-match-patch` `bootstrap-icons` を npm から入れてローカルに置き、`index.html` の CDN の URL を差しかえる。Tailwind は Play CDN が使えないので、`tailwindcss@3` の CLI に `index.html` を読ませて CSS を書き出し、ページ内の `tailwind.config` と同じ内容を渡す。Google Fonts は CSS と woff2 を落としてローカル参照にする。
2. `diff-match-patch` の npm 版は `module.exports` を使うため、その `<script>` の前後だけ `window.module` を差しかえて元に戻す。ここで `window.module` を出しっぱなしにすると React と PeerJS が UMD 側の分岐に入り、`React is not defined` で真っ白になります。
3. PeerJS の公開シグナリングサーバ（`0.peerjs.com`）に届かないので、`node <skill>/scripts/peer-server.mjs 9000` を立て、`new Peer(...)` の第2引数に `{ host: '127.0.0.1', port: 9000, path: '/', secure: false }` を渡す。**端末どうしの実際のやり取りはブラウザ間の WebRTC のままなので、撮れた画面は本物と同じです。** このアプリにCSPは設定されていないので、`connect-src` を足す作業は要りません。

### 撮影のシナリオで踏んだ落とし穴

- **ふりがなが `<ruby><rt>` ではなく `span` の重ね**で作られています（`index.html` の `Rb` コンポーネント）。`capture.mjs` の `click()` は `<rt>` を落としてから照合しますが、この作りだとふりがなが落ちません。`buttons()` が返すとおり `先生せんせいと接続せつぞく` の形で押す必要があります。
- 名簿の行は `button` ではないので `buttons()` に出てきません。文字から要素を探して `click()` する補助を書いています。
- 添削のドラッグは、`.genko-cell[data-idx]` の座標を取って本物のマウスで動かしています。`pointerdown` から `pointerup` までのあいだにスクリーンショットを挟むと、選択中の色が付いた画面が撮れます。
- 印刷のレイアウトは、`window.print` を空の関数に差しかえてから印刷ボタンを押し、`emulateMedia({ media: 'print' })` に切り替えて撮っています。ビューポートをA4横と同じ 1123×794 にすると、余白なしで1枚に収まります。
- 提出の確認は SweetAlert2 のダイアログなので、押すボタンは `はい、ていしゅつします` です。

シナリオの本体は納品物に含めていません。必要なら上のメモから再構成できます。

連載「教室で使えるかもしれないもの作り」の書きぶりに合わせています。

- 太字、斜体、表、`→` `／` `：` `▲` などの記号を使っていません。Markdown は見出しだけです。機械的に確認済み（太字0、表0、記号0）。

- 絵文字は見出しだけに置いています。本文には入れていません。
- 見出しは基本の並びに、📱 と ✨ のあいだへ2本だけ足しました。`🔌 サーバーもアカウントもなく、四桁の数字だけでつながる` と `✏️ 原稿用紙の上を、なぞって赤ペン` です。このアプリの目玉が既存の見出しに収まらなかったためです。
- 「三つのいいことが期待できます。」「一つ目は、〜ことです。」の型を ✨ で使っています。
- 結びは #9 と同じ一文にしました。
- 本文の字数は7,406字です。

### 意識して書かなかったこと

- **教室での出来事を実体験として書いていません。** 「使ってみたら子どもたちが〜」は一つもありません。作った理由と「〜だと思います」「〜と思って作りました」までにとどめています。実際の授業での様子は、書き手が足すところとして空けてあります。
- **効果を言い切っていません。** 「返却が速くなります」ではなく「短くなる」「〜だと思います」にしています。
